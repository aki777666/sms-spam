    最佳模型的混淆矩陣

    指標怎麼看

    • Precision：被判成垃圾的訊息中，真的是垃圾的比例；越高代表越少把正常訊息誤判。
    • Recall：所有垃圾簡訊中，被成功抓到的比例；越高代表越少漏抓。
    • F1：兼顧 Precision 與 Recall 的分數，本專題以它選出最佳模型。
    • 為什麼不只看 Accuracy：垃圾簡訊只佔一成多，全部猜「正常」也有很高的 Accuracy，卻一則都抓不到。
